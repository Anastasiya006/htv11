# Agent screenshots

Save PNG, JPEG, or WebP screenshots here. New images saved during the current Gemini turn appear as View image cards on Gemmi. Maximum 10 MB per image; the latest eight images are shown. Files must be directly inside this folder; symlinks and SVG/HTML are not served.

Prompt example:

> Take a screenshot of the simulator using your available browser tool and save it as screenshots/simulator.png.

Gemini needs an actual browser/screenshot tool to capture a page. This feature displays files; it does not install such a tool. You can also copy an image here while Gemini is running a turn.
